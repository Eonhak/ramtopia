# RAMTOPIA

브라우저에서 플레이하는 아이소메트릭 로우폴리 턴제 전략 게임입니다. 전사 이동, 안개 탐험, 도시 점령, 전투, 훈련, 도시 성장, AI 왕국과 승패 판정을 제공합니다. EXE 설치는 필요하지 않습니다.

## 웹에서 플레이

GitHub Pages 배포 후 주소: https://eonhak.github.io/ramtopia/

`main`에 푸시하면 **Actions → Deploy Web Game**에서 빌드하고 `gh-pages` 브랜치에 정적 사이트를 게시합니다. Actions 아티팩트 저장 공간은 사용하지 않습니다.

최초 한 번 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: gh-pages / (root) → Save**를 설정해야 합니다. `gh-pages`가 없으면 Deploy Web Game 실행이 성공한 뒤 선택하세요. 저장소 공개 여부와 요금제에 따라 GitHub Pages 사용 가능 여부가 달라질 수 있습니다.

## 로컬 실행

Node.js 20.19+ 또는 22.12+에서:

```sh
npm ci
npm run dev -- --port 3000
```

브라우저로 http://localhost:3000 에 접속합니다. 배포 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`입니다.

## 나라 선택과 지도

시작 전에 로마·고구려·고대 이집트·아케메네스 페르시아·한나라·고대 그리스·몽골 제국·마우리아 왕조 중 하나를 선택합니다. 나라별 수도 이름과 시작 기술이 적용되며, 유닛의 투구·복식·방패와 도시의 건축 형태도 다릅니다. 국가 선택 카드에서 실제 게임 그래픽을 미리 볼 수 있습니다. 시작 기술은 게임을 위한 특성입니다. 새 게임에서 나라를 다시 선택할 수 있습니다.

지형, 수도와 중립 마을 위치, 주변 자원은 매 게임 새로 생성됩니다. 도시들이 고립되지 않도록 걷기 가능한 연결 경로를 확보합니다. 내 수도·내 도시·적 도시·중립 마을은 깃발/건물 형태와 **글자 배지**로 구분됩니다. 자원 그림은 지형 위에 마지막으로 그려져 나무에 가려지지 않으며, 수확하면 그림이 없어지고 완료 표시로 바뀝니다.

## 조작

- 전사를 누르면 **흰 테두리의 이동 타일**과 **붉은 공격 타일**이 동시에 표시됩니다. 해당 타일을 다시 누르면 바로 행동합니다. 유닛 정보는 작은 표시줄로만 나타납니다.
- 이동·공격은 대각선을 포함한 **8방향**입니다. 양옆이 모두 막힌 모서리를 뚫고 이동할 수는 없습니다. 숲 진입은 이동 비용이 1 증가하지만, **기본 이동력 1인 유닛은 숲 페널티가 없습니다**. 기병·기사는 숲 한 칸에 이동력 2를 사용합니다.
- 유닛이 **3킬**을 달성하면 무료로 한 번 **정예 진급**할 수 있습니다. 최대 체력이 5 증가하고 즉시 완전히 회복합니다. 킬 수는 개별 유닛에 저장됩니다.
- **휴식**은 행동을 사용해 체력을 3 회복합니다. 의술 연구 후에는 5 회복합니다.
- 자원은 **새 게임마다 마을 주변에 무작위 배치**됩니다. 사냥을 연구하면 자기 도시 영토 안의 동물에 별을 써서 인구를 얻습니다. 열매·목재·곡물·물고기·광석도 해당 연구를 마쳐야 수확할 수 있습니다. 개발은 한 번만 가능합니다.
- 인구가 `현재 레벨 + 1`에 도달하면 도시가 성장하고 매 턴 수입이 1별 증가합니다. **레벨 1: 전사 / 레벨 2: 궁수·기병·방패병 / 레벨 3: 투석기·기사**. 상위 병종은 해당 기술 연구도 필요하며, 생산한 유닛은 다음 턴부터 행동합니다.
- 도시는 자원 목록과 생산 가능한 병종을 보여줍니다. 각 도시의 레벨은 독립적으로 적용됩니다. 전사가 있는 도시는 **도시 관리 / 전사 선택**으로 전환합니다.
- 상단 **연구**에서 아래 3단계 계통을 순서대로 연구합니다. 여러 계통이 공유하는 사냥은 한 번만 연구합니다.

| 계통 | 1단계 | 2단계     | 3단계     |
| ---- | ----- | --------- | --------- |
| 암살 | 정찰  | 은신      | 암살술    |
| 해전 | 낚시  | 항해      | 해전술    |
| 궁병 | 사냥  | 궁술      | 정밀 사격 |
| 기동 | 사냥  | 도로      | 기병      |
| 공성 | 사냥  | 벌목      | 투석기    |
| 강철 | 등산  | 제련      | 기사      |
| 농업 | 채집  | 농업      | 방어술    |
| 해양 | 낚시  | 항해      | 의술      |
| 탐험 | 정찰  | 지도 제작 | 교역      |

등산 전에는 산 진입이 불가능하며, **항해 연구 후 바다에 진입하면 수송선에 승선**합니다. 수송선은 이동 2이며 공격·반격이 불가능합니다. 도로 연구 후 자기 영토의 타일에 2별로 도로를 건설하면 연결된 도로 사이 이동 비용이 절반이 됩니다. 궁수는 도시 레벨 2·궁술 연구 후 7별로 생산하며 사거리 2, 체력 8, 공격 5입니다. 정밀 사격 연구 시 궁수 공격력이 7이 됩니다. 원거리 공격은 화살/포탄 애니메이션으로 표시됩니다. 투석기는 사거리 3이며 원거리 처치 시 제자리에 머뭅니다. 교역은 도시마다 턴 수입 +2별, 의술은 휴식 회복량 +2를 제공합니다.

- 중립·적 마을은 전사로 진입하면 점령되며 **그 유닛의 행동이 종료**됩니다. 적 유닛을 처치하면 살아남은 공격 유닛이 해당 칸으로 진입하고 행동을 마칩니다. 붉은 수도를 점령하면 승리합니다.
- **턴 마치기**로 AI 행동과 도시 수입을 처리합니다.
- 모바일에서는 한 손가락으로 지도를 이동하고, **두 손가락을 벌려 확대 / 모아 축소**합니다. 손가락 사이 중심을 기준으로 확대되며, 한 손가락을 떼면 나머지 손가락으로 계속 이동할 수 있습니다. PC에서는 드래그, 마우스 휠 또는 + / −를 사용합니다. ⌖는 시점 초기화, Esc는 선택 닫기입니다.

자체 제작한 벡터 로우폴리 타일·유닛을 Canvas로 렌더링하며 외부 게임 에셋은 사용하지 않습니다. PC와 모바일에서 화면 안 행동 패널을 지원합니다. 외부 API 키는 필요하지 않습니다. 글꼴은 Google Fonts를 사용하며 연결이 없으면 시스템 글꼴을 사용합니다.

## 배와 해전

승선한 유닛을 선택해 **정찰선 개조**(5별, 항해 필요) 또는 **전투함 개조**(10별, 해전술 필요)를 선택합니다. 정찰선은 이동 3·공격 3·사거리 2·낮 시야 3, 전투함은 이동 2·공격 7·사거리 3입니다. 바다에서는 원래 육상 유닛 대신 배가 표시됩니다. 상륙하면 원래 유닛으로 돌아오며 배의 개조는 해제됩니다. 육상 유닛 종류와 정예 진급은 유지됩니다.

해전 연구 계통: **낚시 → 항해 → 해전술**. 기존 낚시 → 항해 → 의술 계통과 선행 기술을 공유합니다.

## 낮·밤과 안개

턴 1은 낮, 턴 2는 밤이며 이후 매 턴 교대합니다. 기본 육상 시야는 주변 1칸(낮 8방향, 밤 4방향)입니다. 정찰 연구는 낮의 육상 시야를 2칸으로 늘리지만 밤에는 1칸입니다. 시작 직후 대부분의 지도는 안개에 가려집니다. 탐험한 지형은 기억되지만 적 유닛은 현재 시야 안에서만 보입니다. 지도 제작도 적의 실시간 위치까지 공개하지 않습니다.

암살자 연구 계통: **정찰 → 은신 → 암살술**. 레벨 2 도시에서 10별로 훈련하며 낮에는 이동 1·공격 1, 밤에는 이동 3·공격 10입니다. 밤에는 숲의 이동 비용도 적용되며, 배에 탄 동안에는 배의 능력치를 사용합니다.

자원은 일부 타일에만 생성됩니다. 시작 도시 주변의 동물·열매는 확보하되 빈 타일도 보장합니다.

## 브라우저 테스트

```sh
npx playwright install chromium
npm run dev -- --port 3000
# 다른 터미널에서
npm test
```

설치된 Chromium을 사용하려면 `CHROMIUM_PATH=/usr/bin/chromium npm test`를 실행합니다. 실제 브라우저에서 선택, 이동, 전투, 훈련, 성장, 수입, 휴식, 승패, 겹친 타일 선택, 이동·공격 애니메이션, 생산 대기, 점령 후 행동 종료, 자원 개발·도시 성장·수입, 연구·병종·능력, 작은 모바일 정보 표시줄, 실제 멀티터치 확대·축소와 취소 처리를 검사합니다. 테스트용 상태 주입은 Playwright 네트워크 가로채기에서만 수행하며 배포 코드에는 포함하지 않습니다. 웹 배포 작업도 테스트 통과 후에만 게시합니다.

애니메이션은 시스템의 동작 줄이기 설정을 따릅니다.

## 도시 선택과 전투 규칙 (1.8)

도시 바닥을 누르면 설명창 없이 하단에 병종 아이콘이 가로 한 줄로 표시됩니다. 미해금 병종은 비활성으로 표시되며 모바일에서는 좌우로 스크롤합니다. 아이콘 위에는 주변 자원 수확 버튼이 표시됩니다. 도시 위 유닛의 머리를 누르면 유닛을 선택합니다. 중립·적 도시는 관리할 수 없습니다. 유닛 그림 크기를 줄였으며 지도는 25%까지 축소하고 400%까지 확대할 수 있습니다.

유닛은 이동한 뒤 같은 턴에 사거리 안의 적을 공격할 수 있습니다. 공격·도시 점령·휴식은 남은 행동을 종료합니다. 새로 훈련한 유닛은 다음 턴부터 행동합니다. 공격과 반격 피해는 각각 남은 체력 비율에 비례합니다(최소 1, 공격 능력이 없는 배는 0).

턴 종료 후 보유 중인 모든 도시에서 수입을 합산합니다. 도시별 기본 수입은 `레벨`별이며 무역 연구 시 도시마다 2별이 추가됩니다. 연구 가격은 `기본 가격 + 2 × 보유 도시의 (레벨 - 1) 합계`로, 성장한 도시가 많을수록 증가합니다.
