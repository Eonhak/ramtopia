# RAMTOPIA

브라우저에서 플레이하는 아이소메트릭 로우폴리 턴제 전략 게임입니다. 전사 이동, 안개 탐험, 도시 점령, 전투, 훈련, 도시 성장, AI 왕국과 승패 판정을 제공합니다. EXE 설치는 필요하지 않습니다.

## 웹에서 플레이

GitHub Pages 배포 후 주소: https://eonhak.github.io/ramtopia/

`main`에 푸시하면 **Actions → Deploy Web Game**에서 빌드하고 `gh-pages` 브랜치에 정적 사이트를 게시합니다. Actions 아티팩트 저장 공간은 사용하지 않습니다.

최초 한 번 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: gh-pages / (root) → Save**를 설정해야 합니다. `gh-pages`가 없으면 Deploy Web Game 실행이 성공한 뒤 선택하세요. 저장소 공개 여부와 요금제에 따라 GitHub Pages 사용 가능 여부가 달라질 수 있습니다.

## 로컬 실행

Node.js 22.13+에서:

```sh
npm ci
npm run dev -- --port 3000
```

브라우저로 http://localhost:3000 에 접속합니다. 배포 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`입니다.

## 나라 선택과 지도

시작 전에 로마·고구려·고대 이집트·아케메네스 페르시아·한나라·고대 그리스·몽골 제국·마우리아 왕조 중 하나를 선택합니다. 나라별 수도 이름과 시작 기술이 적용되며, 유닛의 투구·복식·방패와 도시의 건축 형태도 다릅니다. 국가 선택 카드에서 실제 게임 그래픽을 미리 볼 수 있습니다. 시작 기술은 게임을 위한 특성입니다. 새 게임에서 나라를 다시 선택할 수 있습니다.

지형, 수도와 중립 마을 위치, 주변 자원은 매 게임 새로 생성됩니다. 도시들이 고립되지 않도록 걷기 가능한 연결 경로를 확보합니다. 내 수도·내 도시·적 도시·중립 마을은 깃발/건물 형태와 **글자 배지**로 구분됩니다. 자원 그림은 지형 위에 마지막으로 그려져 나무에 가려지지 않으며, 수확하면 그림이 없어지고 완료 표시로 바뀝니다.

## 조작

- 전사를 누르면 **흰 테두리의 이동 타일**과 **붉은 공격 타일**이 동시에 표시됩니다. 해당 타일을 다시 누르면 바로 행동합니다. 유닛 정보는 작은 표시줄로만 나타납니다.
- 이동·공격은 대각선을 포함한 **8방향**입니다. 양옆이 모두 막힌 모서리를 뚫고 이동할 수는 없습니다. 숲 진입은 이동 비용이 1 증가하지만, **기본 이동력 1인 유닛은 숲 페널티가 없습니다**. 기병·기사는 숲 한 칸에 이동력 2를 사용합니다.
- 유닛이 **3킬**을 달성하면 무료로 한 번 **정예 진급**할 수 있습니다. 최대 체력이 5 증가하고 즉시 완전히 회복합니다. 킬 수는 개별 유닛에 저장됩니다.
- **휴식**은 행동을 사용해 체력을 3 회복합니다. 의술 연구 후에는 5 회복합니다.
- 자원은 **새 게임마다 마을 주변에 무작위 배치**됩니다. 사냥을 연구하면 자기 도시 영토 안의 동물에 별을 써서 도시 경험치를 얻습니다. 열매·목재·곡물·물고기·광석도 해당 연구를 마쳐야 수확할 수 있습니다. 개발은 한 번만 가능합니다.
- 경험치가 `현재 레벨 + 1`에 도달하면 도시 레벨과 인구가 증가하고 매 턴 수입이 1별 증가합니다. **레벨 1: 전사 / 레벨 2: 궁수·기병·방패병 / 레벨 3: 투석기·기사**. 상위 병종은 해당 기술 연구도 필요하며, 생산한 유닛은 다음 턴부터 행동합니다.
- 빈 도시는 생산 병종 아이콘을 보여줍니다. 자원은 지도에서 해당 타일을 직접 선택해 수확합니다. 각 도시의 레벨은 독립적으로 적용됩니다. 전사가 있는 도시는 **도시 관리 / 전사 선택**으로 전환합니다.
- 상단 **연구**에서 아래 3단계 계통을 순서대로 연구합니다. 여러 계통이 공유하는 사냥은 한 번만 연구합니다.

| 계통 | 1단계 | 2단계     | 3단계     |
| ---- | ----- | --------- | --------- |
| 암살 | 정찰  | 은신      | 암살술    |
| 해전 | 낚시  | 항해      | 해전술    |
| 궁병 | 사냥  | 궁술      | 정밀 사격 |
| 기동 | 사냥  | 도로      | 기병      |
| 공성 | 사냥  | 벌목      | 투석기    |
| 강철 | 등산  | 제련      | 기사      |
| 농업 | 채집  | 농업      | 방어술    |
| 해양 | 낚시  | 항해      | 의술      |
| 탐험 | 정찰  | 동맹 | 교역      |

등산 전에는 산 진입이 불가능하며, **항해 연구 후 바다에 진입하면 수송선에 승선**합니다. 수송선은 이동 2이며 공격·반격이 불가능합니다. 도로 연구 후 자기 영토의 타일에 2별로 도로를 건설하면 연결된 도로 사이 이동 비용이 절반이 됩니다. 궁수는 도시 레벨 2·궁술 연구 후 7별로 생산하며 사거리 2, 체력 8, 공격 5입니다. 정밀 사격 연구 시 궁수 공격력이 7이 됩니다. 원거리 공격은 화살/포탄 애니메이션으로 표시됩니다. 투석기는 사거리 3이며 원거리 처치 시 제자리에 머뭅니다. 교역은 도시마다 턴 수입 +2별, 의술은 휴식 회복량 +2를 제공합니다.

- 중립·적 마을은 전사로 진입하면 점령되며 **그 유닛의 행동이 종료**됩니다. 적 유닛을 처치하면 살아남은 공격 유닛이 해당 칸으로 진입하고 행동을 마칩니다. 붉은 수도를 점령하면 승리합니다.
- **턴 마치기**로 AI 행동과 도시 수입을 처리합니다.
- 모바일에서는 한 손가락으로 지도를 이동하고, **두 손가락을 벌려 확대 / 모아 축소**합니다. 손가락 사이 중심을 기준으로 확대되며, 한 손가락을 떼면 나머지 손가락으로 계속 이동할 수 있습니다. PC에서는 드래그, 마우스 휠 또는 + / −를 사용합니다. ⌖는 시점 초기화, Esc는 선택 닫기입니다.

자체 제작한 벡터 로우폴리 타일·유닛을 Canvas로 렌더링하며 외부 게임 에셋은 사용하지 않습니다. PC와 모바일에서 화면 안 행동 패널을 지원합니다. 외부 API 키는 필요하지 않습니다. 글꼴은 Google Fonts를 사용하며 연결이 없으면 시스템 글꼴을 사용합니다.

## 배와 해전

승선한 유닛을 선택해 **정찰선 개조**(3별, 항해 필요) 또는 **전투함 개조**(5별, 해전술 필요)를 선택합니다. 정찰선은 이동 3·공격 3·사거리 2·낮 시야 3, 전투함은 이동 2·공격 7·사거리 3입니다. 바다에서는 원래 육상 유닛 대신 배가 표시됩니다. 상륙하면 원래 유닛으로 돌아오며 배의 개조는 해제됩니다. 육상 유닛 종류와 정예 진급은 유지됩니다.

해전 연구 계통: **낚시 → 항해 → 해전술**. 기존 낚시 → 항해 → 의술 계통과 선행 기술을 공유합니다.

## 낮·밤과 안개

턴 1은 낮, 턴 2는 밤이며 이후 매 턴 교대합니다. 기본 육상 시야는 주변 1칸(낮·밤 모두 8방향)입니다. 정찰 연구는 낮의 육상 시야를 직선 2칸·대각선 1칸으로 늘려 유닛당 최대 13칸을 보여주며 밤에는 1칸입니다. 시작 직후 대부분의 지도는 안개에 가려집니다. 탐험한 지형은 기억되지만 적 유닛은 현재 시야 안에서만 보입니다. 동맹 연구는 지도를 전체 공개하지 않으며, 수락한 동맹국의 현재 시야를 공유합니다.

암살자 연구 계통: **정찰 → 은신 → 암살술**. 레벨 2 도시에서 4별로 훈련하며 낮에는 이동 1·공격 1, 밤에는 이동 3·공격 10입니다. 밤에는 숲의 이동 비용도 적용되며, 배에 탄 동안에는 배의 능력치를 사용합니다.

자원은 일부 타일에만 생성됩니다. 시작 도시 주변의 동물·열매는 확보하되 빈 타일도 보장합니다.

## 브라우저 테스트

```sh
npx playwright install chromium
npm run dev -- --port 3000
# 다른 터미널에서
npm test
```

설치된 Chromium을 사용하려면 `CHROMIUM_PATH=/usr/bin/chromium npm test`를 실행합니다. 실제 브라우저에서 선택, 이동, 전투, 훈련, 성장, 수입, 휴식, 승패, 겹친 타일 선택, 이동·공격 애니메이션, 생산 대기, 점령 후 행동 종료, 자원 개발·도시 성장·수입, 연구·병종·능력, 작은 모바일 정보 표시줄, 실제 멀티터치 확대·축소와 취소 처리를 검사합니다. 테스트용 상태 주입은 Playwright 네트워크 가로채기에서만 수행하며 배포 코드에는 포함하지 않습니다. 웹 배포 작업도 테스트 통과 후에만 게시합니다.

애니메이션은 시스템의 동작 줄이기 설정을 따릅니다.

## 도시 선택과 전투 규칙 (1.8)

빈 도시를 누르면 설명창 없이 하단에 병종 아이콘이 가로 한 줄로 표시됩니다. 도시 위에 유닛이 있으면 유닛이 우선 선택되며 도시 관리 버튼으로 생산에 전환합니다. 미해금 병종은 비활성으로 표시되며 모바일에서는 좌우로 스크롤합니다. 도시에는 수확 버튼이 없으며, 지도에서 자원 타일을 직접 선택해야 수확할 수 있습니다. 도시 위 유닛의 머리를 누르면 유닛을 선택합니다. 중립·적 도시는 관리할 수 없습니다. 유닛 그림 크기를 줄였으며 지도는 25%까지 축소하고 800%까지 확대할 수 있습니다.

유닛은 이동한 뒤 같은 턴에 사거리 안의 적을 공격할 수 있습니다. 공격·도시 점령·휴식은 남은 행동을 종료합니다. 새로 훈련한 유닛은 다음 턴부터 행동합니다. 공격과 반격 피해는 각각 남은 체력 비율에 비례합니다(최소 1, 공격 능력이 없는 배는 0).

턴 종료 후 보유 중인 모든 도시에서 수입을 합산합니다. 시작 수도의 기본 수입은 `레벨 + 2`별, 점령한 중립 도시의 수입은 `레벨`별이며 무역 연구 시 도시마다 2별이 추가됩니다. 연구 가격은 `기본 가격 + 2 × 보유 도시의 (레벨 - 1) 합계`로, 성장한 도시가 많을수록 증가합니다.

## 계정 서버 (1.9)

상단 로그인 버튼에서 아이디·비밀번호로 가입하고 로그인할 수 있습니다. 닉네임과 계정은 SQLite에 영구 저장하며, HttpOnly 쿠키로 로그인 상태를 복원합니다. 로그인·회원가입 후 모드와 나라를 선택합니다. 세션이 남아 있으면 모드 선택으로 바로 넘어갑니다. 로그아웃하면 로그인 화면으로 돌아갑니다. 멀티플레이 진행은 서버에 저장되며, 싱글플레이 저장은 아직 제공하지 않습니다.

로컬 개발은 터미널 두 개에서 실행합니다.

```sh
npm run server
# 다른 터미널
npm run dev -- --port 3000
```

Vite가 `/api`를 로컬 8080 서버에 연결합니다. 운영 서버는 빌드한 게임도 함께 제공합니다. `.env.example`, Dockerfile과 [Lightsail 배포 안내](deploy/README.md)를 참고하세요. 공개 로그인은 실제 HTTPS 서버 설정 후 사용할 수 있습니다. 서버 검증은 `npm run test:server`입니다. 비밀번호·세션 토큰·계정 DB는 GitHub에 업로드하지 않습니다.

## 싱글·멀티플레이 (2.0)

로그인 후 모드를 선택합니다. **싱글플레이**에서는 내 턴 제한을 5분·10분·무한 중 고른 뒤 나라를 선택하고 기존 AI와 플레이합니다. 새 게임 버튼으로 모드 선택으로 돌아갈 수 있습니다.

**멀티플레이**는 로그인한 2~8명이 초대 방에서 진행합니다.

1. 방장이 방 이름과 플레이어별 턴 제한(5분·10분·무한)을 정해 방을 만듭니다.
2. 초대 링크 또는 10자리 방 코드를 공유합니다. 링크를 받은 사용자는 로그인·회원가입 후 해당 방에 참가합니다.
3. 각자 서로 다른 나라를 선택하고 준비 완료를 누릅니다. 나라 변경은 자신의 준비를 취소하고, 시간 변경은 전원의 준비를 취소합니다.
4. 2~8명 모두 준비하면 방장만 게임을 시작할 수 있습니다.
5. 참가 순서대로 한 명씩 턴을 진행합니다. 서버가 차례·행동·별·성장·연구·전투를 검증하며, 다른 플레이어의 차례에는 행동할 수 없습니다. 제한 시간은 각 플레이어의 차례가 시작할 때마다 새로 부여되며, 시간이 끝나면 연결된 클라이언트의 다음 동기화 시 서버가 자동으로 턴을 넘깁니다. 무한 설정에는 자동 종료가 없습니다.

멀티 지도는 16×16이고 각 나라에 수도와 전사가 주어집니다. 수도를 잃거나 게임을 포기하면 탈락하며 마지막 남은 왕국이 승리합니다. 한 바퀴가 끝날 때 라운드가 증가하고 낮·밤이 바뀝니다. 턴 종료 수입은 자신의 도시 레벨 합계(무역 보너스 별도)입니다. 새 유닛은 다음 자기 차례부터 행동합니다.

멀티 방과 게임 상태는 계정과 같은 SQLite 볼륨에 저장됩니다. 새로고침·재로그인·서버 재시작 뒤 참가 중인 방을 이어서 불러옵니다. 동기화는 약 1.2초 간격이며 변경이 없으면 게임 지도 전체를 다시 전송하지 않습니다. 플레이어마다 자신의 시야와 탐험 기록을 적용해 숨은 적 유닛 좌표와 상대의 별·연구 목록을 보내지 않습니다. 게임 도중 방에서 나가면 포기 처리됩니다. 대기실에서 방장이 나가면 다음 참가자가 방장을 이어받습니다.

검증: `npm run test:server`는 계정 API와 멀티 규칙·방 권한·타이머를 검사합니다. `npm test`는 기존 싱글 게임 테스트와 실제 로그인 브라우저 4개를 이용한 초대·나라 선택·준비·게임 시작·이동·턴 동기화·별 수입·재접속 검사를 포함합니다.

Lightsail 업데이트는 기존 RAMTOPIA 폴더에서 실행합니다.

```sh
cd /home/ubuntu/ramtopia
git pull --ff-only
sudo docker compose --env-file deploy/lightsail.env -f deploy/compose.yaml -f deploy/compose.lightsail.yaml up -d --build --wait
```

접속 주소와 Caddy 설정은 그대로 사용합니다: https://ramtopia.duckdns.org/

## 도시 영역·경험치·성장 보상 (2.2)

왼쪽 위의 점령 퀘스트 표시는 제거했습니다. 도시 영역은 중심과 주변 8칸, 총 3×3으로 시작하며 경계선으로 표시합니다. 자원 수확과 도로 건설은 내 도시가 소유한 영역 안에서만 가능합니다. 도시 레벨만으로 영역은 자동 확장되지 않습니다.

수확한 자원의 경험치가 도시의 `현재 레벨 + 1`에 도달하면 레벨이 오르고 인구가 1 늘어납니다. 넘친 경험치는 유지하며 다음 성장에 사용합니다. 인구는 시작 1명이며 수확 즉시 늘어나지 않습니다. 레벨이 높아질수록 건물 수·크기·장식이 바뀝니다.

레벨업할 때마다 하단의 생산 아이콘 형태로 표시되는 성장 보상 중 하나를 고릅니다. 선택 중에도 지도를 조작할 수 있습니다. 성장 순간에는 황금빛 파동·입자와 레벨 표시가 나타납니다.

- **별 +5**: 즉시 받습니다.
- **성곽**: 도시당 1회. 해당 도시 타일 위의 소유자 유닛에 방어 ×1.5를 적용해 공격·반격으로 받는 피해를 약 1/3 줄입니다. 도시를 벗어나거나 적 유닛이 서 있으면 적용하지 않습니다.
- **영역 확장**: 도시당 최대 2회. 반경 1 → 2 → 3으로 늘어나며 이웃 도시의 기존 영역은 빼앗지 않습니다.
- **왕국 거인**: 레벨 5부터 선택할 수 있습니다. 체력 30·공격 12·이동 1이며 도시 영역 안의 빈 육지에 등장합니다. 다음 자기 턴부터 행동하고, 일반 생산으로는 얻을 수 없습니다. 배치 공간이 없으면 다른 보상을 선택할 수 있습니다.

시작 별은 **3**, 레벨 1 시작 수도의 기본 턴 수입은 **3**, 점령한 중립 도시는 **레벨당 1별**입니다. 무역 보너스는 도시당 +2입니다. 보병 3, 궁수·기병·방패병 3, 암살자 4, 투석기 5, 기사 6별로 조정했습니다. 정찰선 개조는 3, 전투함 개조는 5별입니다.

싱글과 멀티에 같은 규칙을 사용합니다. 기존 멀티 저장 게임의 이전 인구 진행치는 경험치로 옮기고 인구를 레벨에 맞춥니다. 기존 게임에서 이미 보유한 별을 초기화하지 않으며 새 게임부터 시작 별 3을 적용합니다.

중립 마을이나 적 도시에 진입한 턴에는 점령되지 않습니다. 다음 자기 턴에 해당 유닛을 선택하고 **마을 점령**을 누르면 내 도시가 되며 유닛의 행동을 소모합니다. 마을을 떠나 재진입하면 다시 다음 턴까지 기다립니다. 적 수도도 다음 자기 턴의 점령이 완료되어야 상대가 탈락합니다. 유닛 체력은 머리 위 숫자로 표시합니다.

## 화면과 공격 연출 (2.3)

보병 생산은 3별입니다. 내 도시 아래에는 경험치 게이지와 레벨이 표시됩니다. 투석기는 대형 차대와 발사대를 갖추며 장전 후 돌을 던집니다. 궁수는 활을 당긴 뒤 화살을 쏘며, 화살과 돌에는 각각 비행 궤적과 명중 효과가 있습니다. 이 공격 연출은 멀티플레이에도 전달됩니다. 연구창의 48px 닫기 버튼은 내용 스크롤과 분리됩니다. 화면의 에버그린 명칭은 제거했습니다.

## 메뉴와 재접속 (2.4)

우측 상단 메뉴 → 메인 화면으로 싱글·멀티 선택 화면에 돌아갑니다. 멀티 방을 탈퇴하지 않으면 서버의 진행 상태를 유지하며 메인 화면에서 이어할 수 있습니다. 같은 계정으로 웹을 닫았다가 다시 열면 진행 중인 방을 복원합니다. 네트워크 복구·화면 복귀 시에도 동기화하고, 자동 복구가 실패하면 메인 화면의 ‘진행 중인 게임 다시 찾기’를 사용합니다. 서버의 턴 제한 시간은 접속 여부와 관계없이 적용됩니다. 유닛이 있는 타일을 다시 누르면 도시·자원 등 아래 타일이 선택됩니다.

## 유닛 정보·아이디 로그인 (2.5)

기사는 말 없이 갑옷·방패·기창을 갖춘 중장보병으로 표시합니다. 생산 아이콘은 이름·별 가격만 표시하며, 우측 위 i 버튼으로 능력치와 필요 연구·도시 레벨을 확인합니다. 생산 조건이 맞지 않아도 정보 버튼을 사용할 수 있습니다. 새 계정은 영문·숫자·밑줄 3~24자의 아이디를 사용하며 대소문자를 구별하지 않습니다. 기존 계정도 이전 로그인 정보로 계속 접속할 수 있습니다.

## 방패병 반사 (2.6)

방패병은 육지에서 근접 공격으로 실제 잃은 체력만큼(100%) 공격자에게 피해를 반사합니다. 성곽 감소를 적용한 후의 피해이며 남은 체력을 초과한 피해는 반사하지 않습니다. 공격으로 쓰러져도 해당 반사는 발생합니다. 사거리가 2 이상인 유닛의 공격은 바로 옆에서 맞아도 반사하지 않습니다. 승선한 방패병은 배의 일반 반격 규칙을 따릅니다. 기사는 말이 없는 외형으로 변경하며 기존 능력치는 유지합니다.

## 지도와 턴 안내 (2.7)

지도 위 유닛 크기를 확대하고 나무와 자원은 작게 조정했습니다. 행동 로그는 화면에서 제거하며 멀티 응답에도 전달하지 않습니다. 턴이 바뀌면 중앙에 내 턴 또는 현재 플레이어 이름이 잠깐 표시됩니다. 지도 이동은 확대율과 화면 크기에 따른 범위로 제한하여 바깥으로 끝없이 밀 수 없습니다. 지도 위 홍보 문구는 제거했습니다.

정찰 연구의 낮 육상 시야는 기존 최대 25칸에서 최대 13칸으로 축소했습니다. 직선 방향만 2칸까지 보이고 대각선은 1칸까지만 보입니다. 밤에는 인접 대각선을 포함한 8방향을 볼 수 있고 도시·배는 밤에 시야 반경이 줄어듭니다.

## 맵 설정·8인 AI·동맹 (3.0)

싱글과 초대 방에서 맵 크기 12×12·16×16·20×20·24×24, 균형·대륙·군도·삼림 지형을 선택합니다. 대기실 설정은 방장만 변경하며 변경 후 사람 플레이어는 다시 준비해야 합니다. 인원은 AI를 포함해 최대 8명입니다. 방장이 AI를 추가·제거하고 AI별 나라·난이도를 고릅니다. 사람 1명과 AI만으로도 시작할 수 있습니다.

AI는 쉬움·보통·어려움으로 구분합니다. 쉬움은 보병 위주로 천천히 움직이며, 보통은 연구·자원 수확과 다양한 유닛을 사용합니다. 어려움은 더 많은 병력과 발전·공성·함선 개조를 활용합니다. 모두 실제 별 비용, 이동·시야·생산 대기 규칙을 따르며 자기 차례를 자동으로 마칩니다.

지도 제작 연구는 삭제하고 **정찰 → 동맹 → 교역**으로 바꿨습니다. 기존 저장의 지도 제작 연구는 동맹으로 이전합니다. 메뉴 → 동맹·외교에서 자기 턴에 제안하며, 상대도 자기 턴에 수락·거절합니다. 제안에는 동맹 연구가 필요하고 수락에는 필요하지 않습니다. AI는 받은 제안을 자기 턴에 수락합니다.

동맹끼리는 공격하거나 도시를 점령할 수 없으며 현재 시야를 공유합니다. 동맹 해제는 자기 턴에 가능하고, 해제한 쪽은 상대 영토에 있는 자기 유닛 1기(생산 순서상 가장 오래된 유닛)를 잃습니다. 해당 유닛이 없으면 삭제하지 않습니다. 해제한 턴에는 이동·공격·연구·생산·수확·보상 선택 등 남은 모든 행동을 할 수 없고 턴 종료만 가능합니다. 다음 자기 턴에는 다시 행동할 수 있습니다. 상대는 유닛을 잃지 않습니다. 동맹을 해제하면 공유 시야가 사라지고 이미 탐험한 땅의 기억만 남습니다.

벌목 연구 후 내 영토의 일반 숲도 4별로 벌목하여 해당 도시 경험치 2를 얻습니다. 나무는 사라지며 같은 숲을 중복 수확할 수 없습니다. 물에는 물고기, 산에는 광석이 무작위 배치되고 빈 타일도 남습니다. 낚시로 어장을 개발하면 경험치 2, 제련으로 광산을 건설하면 경험치 3을 얻습니다. 연구비는 기본 비용에 추가 도시 하나당 2별, 도시 레벨 상승분마다 2별이 더해집니다. 어려움 AI는 연구비를 저축하고 자원을 개발하며 궁수 등 병종을 생산하고 탐험 후 중립 도시를 다음 턴에 점령합니다.

AI는 게임마다 확장·군사·내정 성향과 선택 편향을 저장하고, 알려진 영토의 자원·해안·적 병종에 따라 연구와 생산 우선순위를 조정합니다. 보통은 성향 차이가 작고 매 턴 연구 최대 1개·개발 2칸, 어려움은 성향 차이가 크고 연구 최대 2개·개발 4칸입니다. 쉬움은 3턴마다 연구·개발 각 1개를 시도하고 보병 위주로 적은 병력을 운영합니다. 어려움은 예상 피해·반격을 비교해 손해인 공격을 피하고 부상 유닛을 귀환·휴식시키며 원거리 유닛의 사거리를 활용합니다. 난이도에 따른 추가 별이나 공격력 보너스는 없습니다.

전투 예상: 내 유닛을 선택하고 공격 가능한 적 유닛을 약 0.45초 길게 누르면 두 유닛 위에 예상 피해가 표시됩니다. 적을 죽이면 `☠ 처치`, 내 유닛이 반격으로 죽으면 `☠ 전사`가 표시됩니다. 길게 누른 뒤 손을 떼면 공격하지 않고 미리보기가 잠시 유지됩니다. 짧게 누르면 공격하며 드래그·핀치 확대는 미리보기를 취소합니다. 산 위 육상 유닛은 방어 +50%(피해를 1.5로 나눔)를 받으며 성곽과 중복 적용하지 않습니다. 체력·사거리·정예·낮밤·산·성곽·방패병 반사는 실제 서버 전투와 같은 계산을 사용합니다.

멀티 AI는 인간과 AI를 구분해 적대하지 않으며, 동맹이 아닌 상대와 싸웁니다. 동맹 연구를 마치고 다른 AI를 발견하면 동맹을 제안할 수 있고, 수락 후에는 공격 금지·시야 공유가 동일하게 적용됩니다. AI의 무제한 연합을 막기 위해 기존 동맹이 있는 AI에게는 자동 제안하지 않습니다. 동맹인 AI 둘만 생존하면 정상적인 동맹 해제 패널티를 적용하고 대결을 재개합니다.
