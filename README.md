# RAMTOPIA

브라우저에서 플레이하는 아이소메트릭 로우폴리 턴제 전략 게임입니다. 전사 이동, 안개 탐험, 도시 점령, 전투, 훈련, 도시 성장, AI 왕국과 승패 판정을 제공합니다. EXE 설치는 필요하지 않습니다.

## 웹에서 플레이

GitHub Pages 배포 후 주소: https://eonhak.github.io/ramtopia/

`main`에 푸시하면 **Actions → Deploy Web Game**에서 빌드하고 `gh-pages` 브랜치에 정적 사이트를 게시합니다. Actions 아티팩트 저장 공간은 사용하지 않습니다.

최초 한 번 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: gh-pages / (root) → Save**를 설정해야 합니다. `gh-pages`가 없으면 Deploy Web Game 실행이 성공한 뒤 선택하세요. 저장소 공개 여부와 요금제에 따라 GitHub Pages 사용 가능 여부가 달라질 수 있습니다.

## 로컬 실행

Node.js 20.19+ 또는 22.12+에서:

```sh
npm ci
npm run dev -- --port 3000
```

브라우저로 http://localhost:3000 에 접속합니다. 배포 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`입니다.

## 조작

- 전사를 누르면 **흰 테두리의 이동 타일**과 **붉은 공격 타일**이 동시에 표시됩니다. 해당 타일을 다시 누르면 바로 행동합니다. 유닛 정보는 작은 표시줄로만 나타납니다.
- **휴식**은 행동을 사용해 체력을 3 회복합니다.
- 도시를 클릭하면 **전사 훈련**(5별), **도시 성장**(8별)을 선택할 수 있습니다. 전사가 있는 도시는 **도시 관리 / 전사 선택**으로 전환합니다.
- 중립 마을은 전사로 진입하면 점령됩니다. 붉은 수도를 점령하면 승리합니다.
- **턴 마치기**로 AI 행동과 도시 수입을 처리합니다.
- 모바일에서는 한 손가락으로 지도를 이동하고, **두 손가락을 벌려 확대 / 모아 축소**합니다. 손가락 사이 중심을 기준으로 확대되며, 한 손가락을 떼면 나머지 손가락으로 계속 이동할 수 있습니다. PC에서는 드래그, 마우스 휠 또는 + / −를 사용합니다. ⌖는 시점 초기화, Esc는 선택 닫기입니다.

자체 제작한 벡터 로우폴리 타일·유닛을 Canvas로 렌더링하며 외부 게임 에셋은 사용하지 않습니다. PC와 모바일에서 화면 안 행동 패널을 지원합니다. 외부 API 키는 필요하지 않습니다. 글꼴은 Google Fonts를 사용하며 연결이 없으면 시스템 글꼴을 사용합니다.

## 브라우저 테스트

```sh
npx playwright install chromium
npm run dev -- --port 3000
# 다른 터미널에서
npm test
```

설치된 Chromium을 사용하려면 `CHROMIUM_PATH=/usr/bin/chromium npm test`를 실행합니다. 실제 브라우저에서 선택, 이동, 전투, 훈련, 성장, 수입, 휴식, 승패, 작은 모바일 정보 표시줄, 실제 멀티터치 확대·축소와 취소 처리를 검사합니다. 테스트용 상태 주입은 Playwright 네트워크 가로채기에서만 수행하며 배포 코드에는 포함하지 않습니다. 웹 배포 작업도 테스트 통과 후에만 게시합니다.
